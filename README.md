# O grande jogo das palavras

Jogo de adivinhação em português brasileiro, com três direções visuais, rodadas ilimitadas e progresso salvo localmente.

## Como jogar

Abra `index.html` em um navegador moderno. Escolha uma direção, envie uma palavra por vez e use **Pedir pista** quando precisar. Palpites relacionados podem mostrar uma pista editorial; palavras sem pista cadastrada continuam permitidas. Acerte a resposta ou revele-a para encerrar a rodada. **Nova rodada** inicia o próximo caso.

As pistas são escritas para as palavras de cada caso; não há algoritmo de similaridade semântica nem pontuação automática. O jogo funciona sem conta. Se o navegador bloquear o armazenamento local, ainda é possível jogar, mas o progresso não será mantido ao recarregar a página.

**Apagar progresso** remove os palpites e as vitórias da direção selecionada neste navegador, após confirmação.
